The original author's model card declares Apache-2.0. Retain that card,
configuration, and the included standard Apache-2.0 text (fullstop-LICENSE.txt).

Mika's experimental model is MODIFIED: original FP32 ONNX weights were converted
to INT8 using ONNX Runtime 1.28.0 (MatMul and Gather, per-channel QInt8,
MatMulConstBOnly=True). Conversion code and dependency versions are in
scripts/quantize_punctuation.py and scripts/requirements-punctuation.txt.
No retraining or changes to the vocabulary were performed.

The native model runtime is ONNX Runtime 1.28.2 (MIT), extracted from the
hash-pinned CPU/no-TTS sherpa-onnx v1.13.8 SDK. No sherpa-onnx inference library is
linked or distributed in this FullStop prototype. Retain ONNX Runtime's license
and ThirdPartyNotices. Source: https://github.com/microsoft/onnxruntime/tree/v1.28.2

Native tokenization uses unmodified SentencePiece v0.2.1 (Apache-2.0), commit
31646a467d2051eb904e0b45de3a73e91fe1c1e3. Its internal protobuf-lite, Abseil subset,
and Darts notices are included; esaxx's notice is retained conservatively although
the trainer is not linked. Source: https://github.com/google/sentencepiece/tree/31646a467d2051eb904e0b45de3a73e91fe1c1e3
